# Backend API Submodule Card

- purpose: FastAPI route wiring and public backend HTTP contract.
- product/module functionality: health, session CRUD, URL input, tab import/open/search, scrape start, versioned idempotent ingest (`ingest.py`), legacy callback shim, clustering proxy, auth proxy, export, platform route mounting.
- scope boundaries: route definitions and dependency wiring only; domain persistence belongs in `sessions`, `url_input`, `export`, and `platform`.
- connected modules/submodules: Backend platform/session/url/export submodules, AI Engine, Browser Engine, Web UI API client, Ops CLI/MCP tools.
- allowed change types: split routers, move request models beside route groups, add dependency helpers, tighten validation.
- special operating rules: preserve `/api/v1` paths and current JSON shapes; do not weaken callback bearer auth or `BACKEND_AGENT_API_TOKEN` checks on agent tab routes. `POST /api/v1/ingest/v1` (submodule `ingest.py`, included from `routes.py` which stays the aggregator) is the single versioned idempotent ingest endpoint: `IngestResultV1` (capture_id, attempt>=1, session_id, url, status, content, metadata, auth_used, fetched_at), bearer `BACKEND_CALLBACK_TOKEN` via the shared callback auth. It returns `200 applied`/`200 ignored{duplicate_capture_id|stale_capture}`/`404 session`/`409 url-not-registered`/`422` — replay/stale is a 200 (the writer did nothing wrong; the receiver owns dedupe), NEVER a 4xx browser-engine would miscount as a callback failure. Registration stays the dispatcher's job (B3): ingest 409s an unregistered url rather than auto-registering, so a token holder cannot inject arbitrary urls. Backend is the SINGLE ai-engine `/index` writer: applied success captures forward asynchronously (`forward_capture_index`, per-`(session,url)` lock + latest-applied re-check → `superseded` skip); `GET /scrape/status/{id}` overlays ledger `ai_index_failed`/`ai_index_pending`/`downstream_errors` onto the browser payload (merge, never replace). `POST /api/v1/callback/scrape-complete` is a deprecated thin adapter over the same ingest path (`attempt=0`, synthetic capture_id, receipt-time newest-wins = pre-ingest behavior, unchanged legacy response shape, logs `ingest.legacy_callback_deprecated`).
- current stubs/placeholders: scrape trigger errors are currently not persisted as a durable backend status; tab import jobs have status polling but no cancellation route.
- irrelevant or incomplete code to remove/rework: mixed route groups should be split into focused router modules without changing URLs.
- docs that must stay aligned: Backend Core card, Backend Sessions card, Web UI API card, `docs/ARCHITECTURE.md`, `docs/TESTING.md`.
- local validation commands/checks: `make test-backend`; focused files `tests/unit/test_backend_tab_workflows.py`, `tests/unit/test_ingest_v1.py`; integration smoke for route changes.
